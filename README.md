# 다낭 · 호이안 트래블월렛 수수료 무료 ATM 지도 (`freeAtm`)

베트남 다낭(Da Nang)과 호이안(Hoi An) 여행 시 **트래블월렛(VISA)** 카드로 **현지 ATM 기기 수수료(Surcharge) 없이(0동)** 현금을 출금할 수 있는 ATM 위치를 구글 지도 기반 웹페이지로 한눈에 확인할 수 있는 프로젝트입니다.

## ✨ 주요 기능 (`index.html`)

* **구글 지도 한국어 타일 + 커스텀 마커**: 별도 API 키 없이 한국어 구글 지도 위에 **1순위 VPBank(초록)** · **2순위 ACB(파랑)** · **주요 관광지 기준점(노랑)** 마커를 한눈에 표시
* **도시 / 은행별 필터링 & 키워드 검색**: 전체(16곳) / 다낭(10곳) / 호이안(6곳), 은행별(`VPBank` / `ACB`), 관광지명 검색 지원
* **내 위치 기반 거리순 정렬**: 모바일 브라우저 GPS 연동 시 현재 위치에서 가장 가까운 무료 ATM 순 정렬
* **원클릭 길찾기 & 그랩(Grab) 주소 복사**: 선택한 ATM의 구글 지도 열기, 도보 길찾기, 그랩 입력용 베트남 도로명 주소 원클릭 복사 및 Google Maps Embed 미리보기 지원

## ⚠️ 현지 ATM 출금 필수 주의사항

1. **보라색 TPBank 주의**: 과거 무료였던 **TPBank**(보라색+주황색 로고)는 정책 변경으로 현재 약 **3~3.3%(또는 건당 약 55,000동)** 수수료가 부과되므로, 반드시 **초록색 간판의 `VPBank`**를 우선 이용하세요.
2. **DCC(원화 환산 결제) 거절**: 출금 과정에 원화(`KRW`)로 환산해 인출할지 묻는 화면이 나오면 무조건 **`VND(현지 통화)`** 또는 **`Without Conversion`**을 선택하세요.
3. **트래블월렛 월 무료 한도**: 트래블월렛 자체 혜택은 **월 $500(USD 상당액) 이하**까지 무료이며, 초과분에는 **2%** 수수료가 부과됩니다.
4. **비밀번호(PIN) 입력**: 카드 비밀번호 **4자리**를 입력하고, 6자리를 요구하는 구형 기기에서만 뒤에 **`00`**을 붙여 입력하세요.
5. **승인 직전 수수료 확인**: 화면에 현지 수수료(`Fee / Surcharge`)가 `0 VND`가 아닌 금액으로 표시되면 즉시 취소(`Cancel`)하세요.
